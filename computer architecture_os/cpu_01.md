# [ 01 - 1 컴퓨터 구조를 알아야 하는 이유 ]

> **좋은 개발자**가 되기 위해서는 프로그래밍 언어의 문법뿐만 아니라 컴퓨터의 근간을 이해해야 한다.

### 컴퓨터의 근간

* **컴퓨터 구조**
* **운영체제**

컴퓨터의 근간을 이해하면 다음과 같은 능력을 기를 수 있다.

1. **문제 해결 능력**
2. **성능 · 용량 · 비용을 고려한 개발**

### 1. 문제 해결 능력

컴퓨터 구조를 이해하면 문법에만 의존하는 것이 아니라,
컴퓨터에서 발생한 문제를 **분석하고 원인을 찾아 해결**할 수 있다.

즉, 컴퓨터를 단순히 사용하는 대상이 아니라 **분석하고 이해하는 대상**으로 바라볼 수 있다.

### 2. 성능 · 용량 · 비용

개발한 프로그램에 필요한 성능과 용량을 고려하여

* 어떤 컴퓨터를 사용할지
* 어떤 하드웨어가 필요한지
* 어떤 클라우드 서비스를 선택할지

등을 판단할 수 있다.

# [ 01 - 2 컴퓨터 구조의 큰 그림 ]

## 컴퓨터가 이해하는 두 가지 정보

컴퓨터가 이해하고 처리하는 정보는 크게 **데이터와 명령어**로 나눌 수 있다.

### 데이터

* 숫자, 문자, 이미지, 동영상 등의 정보
* 컴퓨터 내부에 저장되거나 컴퓨터와 주고받는 정보
* 컴퓨터에서는 데이터를 **0과 1**로 표현한다.

### 명령어

* 컴퓨터를 **실질적으로 움직이는 정보**
* 컴퓨터는 결국 명령어를 처리하는 기계
* 데이터는 명령어를 실행하기 위한 일종의 재료

> 예시
> **"안녕하세요를 출력하라"** → 명령어
> **"안녕하세요"** → 데이터

# 컴퓨터의 네 가지 핵심 부품

컴퓨터를 구성하는 핵심 부품은 다음과 같다.

1. **CPU**
2. **메모리(RAM)**
3. **보조 기억 장치**
4. **입출력 장치**

---

## 1. 메모리

메모리는 **현재 실행되는 프로그램의 명령어와 데이터를 저장하는 부품**이다.

주로 **RAM**을 의미하며, 프로그램이 실행되기 위해서는 해당 프로그램의 명령어와 데이터가 메모리에 저장되어 있어야 한다.

* 메모리는 **주소(Address)**를 이용하여 필요한 정보를 찾는다.
* RAM은 전원이 꺼지면 저장된 내용이 사라지는 **휘발성 저장 장치**이다.

> **메모리 = 현재 실행할 정보를 저장**

---

## 2. CPU

CPU는 메모리에 저장된 명령어를 **읽고, 해석하고, 실행하는 부품**이다.

### CPU의 핵심 구성 요소

| 구성 요소    | 역할                  |
| -------- | ------------------- |
| **ALU**  | 산술·논리 연산을 수행        |
| **레지스터** | CPU 내부의 작은 저장 장치    |
| **제어장치** | 명령어를 해석하고 제어 신호를 보냄 |

* **ALU (Arithmetic Logic Unit)** → 계산기 역할
* **레지스터** → CPU가 사용할 데이터와 명령어 등을 임시 저장
* **제어장치** → 메모리 읽기/쓰기 등의 **제어 신호**를 생성

### CPU의 기본 동작 흐름

**메모리 → CPU → 연산 및 처리 → 결과 저장**

CPU는 메모리에서 명령어를 가져와 해석하고, 필요한 데이터를 가져와 연산한 뒤 그 결과를 레지스터나 메모리에 저장한다.

---

## 3. 보조 기억 장치

보조 기억 장치는 **많은 양의 데이터를 장기간 저장하기 위한 장치**이다.

대표적으로:

* HDD
* SSD

RAM과 비교하면 상대적으로 저렴하고 대용량 저장이 가능하며, **전원이 꺼져도 데이터가 유지**된다.

> **메모리 = 현재 실행할 정보를 저장**
> **보조 기억 장치 = 보관할 정보를 저장**

---

## 4. 입출력 장치

입출력 장치는 컴퓨터 외부와 연결되어 **컴퓨터 내부와 정보를 주고받는 장치**이다.

예시:

* 키보드
* 마우스
* 모니터
* 프린터
* 스피커

---

# 메인보드와 시스템 버스

## 메인보드

**메인보드(Motherboard)**는 컴퓨터의 핵심 부품들을 연결하는 기판이다.

CPU, 메모리, 보조 기억 장치, 입출력 장치 등이 메인보드를 통해 연결되고 정보를 주고받는다.

## 시스템 버스

**시스템 버스(System Bus)**는 컴퓨터의 주요 부품들이 정보를 주고받는 통로이다.

### 시스템 버스의 종류

| 버스         | 역할             |
| ---------- | -------------- |
| **주소 버스**  | 주소를 주고받음       |
| **데이터 버스** | 명령어와 데이터를 주고받음 |
| **제어 버스**  | 제어 신호를 주고받음    |

---

## 전체 흐름 정리

```text
                 ┌─────────────┐
                 │     CPU     │
                 │ ALU / 레지스터│
                 │   / 제어장치  │
                 └──────┬──────┘
                        │
                ┌───────┴───────┐
                │   시스템 버스   │
                └───────┬───────┘
          ┌─────────────┼─────────────┐
          │             │             │
     ┌────▼────┐   ┌────▼─────┐   ┌───▼────┐
     │  메모리  │   │ 보조 기억 │   │ 입출력  │
     │   RAM   │   │ 장치 SSD │   │  장치   │
     └─────────┘   │   / HDD  │   └────────┘
                   └──────────┘
```

### 핵심만 기억하기

> **CPU** → 명령어를 읽고 실행
> **메모리(RAM)** → 실행할 프로그램과 데이터 저장
> **보조 기억 장치** → 데이터를 장기간 저장
> **입출력 장치** → 외부와 정보 교환
> **메인보드** → 핵심 부품 연결
> **시스템 버스** → 부품 사이의 정보 전달
