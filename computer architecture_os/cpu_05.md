# 05-1. 빠른 CPU를 위한 설계 기법

## 📌 학습 목표

* 클럭(Clock)이 무엇인지 이해하기
* 코어(Core)와 멀티코어(Multi-Core)가 무엇인지 이해하기
* 하드웨어 스레드와 소프트웨어 스레드의 차이 이해하기
* CPU의 성능을 높이는 방법 이해하기

---

# 1. 조금이라도 더 빠른 CPU를 만들려면?

CPU의 성능을 높이기 위해 가장 먼저 생각할 수 있는 방법은 **클럭 속도를 높이는 것**이다.

컴퓨터의 부품들은 일정한 **클럭 신호**에 맞춰 동작하고, CPU는 **명령어 사이클**이라는 정해진 흐름에 따라 명령어를 실행한다.

따라서 처음에는 다음과 같이 생각할 수 있다.

> **클럭 속도를 높이면 CPU가 더 빠르게 동작하지 않을까?**

---

## ⏱️ 클럭(Clock)이란?

클럭 속도는 **Hz(헤르츠)** 단위로 측정한다.

**1Hz = 1초에 클럭이 1번 반복**

따라서 2.5GHz라면 이론적으로 1초에 약 25억 번의 클럭이 반복된다.

예를 들어 어떤 CPU가

* 기본 클럭: 2.5GHz
* 최대 클럭: 4.9GHz

라면 기본적으로 약 25억 번, 필요할 때는 최대 약 49억 번의 클럭이 1초에 발생할 수 있다.

### ⚠️ 클럭만 계속 높이면 될까?

그렇지는 않다.

클럭 속도를 필요 이상으로 높이면 **발열과 전력 소모가 증가**할 수 있다.

따라서 CPU 성능을 높이는 방법은 단순히 클럭 속도를 높이는 것만으로 해결할 수 없다.

---

# 2. 클럭 이외에 CPU를 빠르게 만드는 방법

클럭 속도를 높이는 것 외에도 CPU의 성능을 높이는 대표적인 방법이 있다.

### ① 코어 수를 늘린다

* 듀얼 코어(Dual-Core)
* 쿼드 코어(Quad-Core)
* 멀티 코어(Multi-Core)

### ② 스레드 수를 늘린다

* 멀티스레드 프로세서
* 하드웨어 스레드 증가

즉, CPU의 성능을 높이는 방법을 크게 보면

> **클럭 속도 + 코어 수 + 스레드 수**

등을 고려할 수 있다.

---

# 3. 코어(Core)란?

그동안 CPU를

> **명령어를 가져와 해석하고 실행하는 부품**

이라고 생각했다.

그런데 CPU 내부에는 실제로 **명령어를 실행하는 핵심 부품이 여러 개 존재할 수 있다.**

이러한 명령어 실행의 핵심 단위를 **코어(Core)**라고 한다.

즉,

> **코어 = CPU 내부에서 명령어를 실행하는 핵심적인 처리 장치**

라고 이해할 수 있다.

---

## 🧠 멀티코어(Multi-Core)

하나의 CPU 안에 여러 개의 코어가 존재하는 프로세서를 **멀티코어 프로세서**라고 한다.

예를 들어,

```text
싱글 코어 CPU

[ CPU ]
   ↓
[ Core 1 ]
```

```text
듀얼 코어 CPU

[ CPU ]
   ├── [ Core 1 ]
   └── [ Core 2 ]
```

```text
쿼드 코어 CPU

[ CPU ]
   ├── [ Core 1 ]
   ├── [ Core 2 ]
   ├── [ Core 3 ]
   └── [ Core 4 ]
```

### ❓ 코어가 많으면 CPU가 그만큼 빨라질까?

**꼭 그렇지는 않다.**

코어가 2개라고 해서 무조건 1개일 때보다 2배 빠르고,
코어가 4개라고 해서 무조건 4배 빠른 것은 아니다.

중요한 것은 **여러 코어에 작업을 얼마나 적절하게 분배할 수 있는가**이다.

따라서 단순히 코어의 개수만 보는 것이 아니라 **프로그램이 여러 코어를 얼마나 잘 활용하는지**도 중요하다.

---

# 4. 스레드(Thread)란?

스레드는 크게 **하드웨어 스레드**와 **소프트웨어 스레드**로 나누어 생각할 수 있다.

둘은 이름은 같지만 의미가 다르다.

---

# 5. 하드웨어 스레드

하드웨어 스레드는

> **하나의 코어가 동시에 처리할 수 있는 명령어의 단위**

라고 이해할 수 있다.

예를 들어,

### 1코어 1스레드

하나의 코어가 한 번에 하나의 명령어 흐름을 처리한다.

```text
Core 1
  ↓
Thread 1
```

### 2코어 4스레드

코어가 2개이고 각각 2개의 하드웨어 스레드를 지원한다면,

```text
Core 1 → Thread 1
       → Thread 2

Core 2 → Thread 3
       → Thread 4
```

따라서 **2코어 4스레드 CPU**가 된다.

즉,

> 코어의 개수와 하드웨어 스레드의 개수는 같을 필요가 없다.

---

## 🧩 멀티스레드 프로세서

하나의 코어가 여러 개의 하드웨어 스레드를 지원하여 여러 명령어 흐름을 처리할 수 있는 CPU를 **멀티스레드 프로세서**라고 한다.

하드웨어 스레드는 **논리 프로세서(Logical Processor)**라고도 부른다.

---

# 6. 하드웨어 스레드를 어떻게 여러 개 만들 수 있을까?

핵심은 **레지스터**이다.

CPU가 명령어를 실행하기 위해서는 여러 레지스터를 사용한다.

따라서 하나의 코어에 여러 개의 **레지스터 묶음**을 두면, 여러 명령어 흐름의 상태를 저장하면서 여러 하드웨어 스레드를 처리할 수 있다.

간단하게 표현하면:

```text
하나의 코어
   │
   ├── 레지스터 묶음 ① → 하드웨어 스레드 ①
   │
   └── 레지스터 묶음 ② → 하드웨어 스레드 ②
```

따라서

> **하드웨어 스레드가 여러 개인 CPU를 구현하는 데 레지스터가 중요한 역할을 한다.**

---

# 7. 소프트웨어 스레드

소프트웨어에서 말하는 스레드는 의미가 조금 다르다.

> **하나의 프로그램에서 독립적으로 실행되는 작업의 단위**

라고 이해할 수 있다.

예를 들어 메모장 같은 프로그램에서 사용자가 글을 입력한다고 생각해보자.

프로그램이 다음 작업을 동시에 수행하고 싶을 수 있다.

1. 입력한 내용을 화면에 보여주기
2. 입력한 내용의 맞춤법 검사하기
3. 입력한 내용을 자동으로 저장하기

이러한 작업들을 여러 스레드로 나누어 처리할 수 있다.

```text
하나의 프로그램
       │
       ├── 스레드 1 → 화면에 입력 내용 표시
       ├── 스레드 2 → 맞춤법 검사
       └── 스레드 3 → 자동 저장
```

---

# 8. 1코어 1스레드 CPU에서도 여러 소프트웨어 스레드를 만들 수 있을까?

**가능하다.**

처음에는 조금 헷갈렸던 부분이다.

> "CPU에 하드웨어 스레드가 하나뿐이라면 소프트웨어 스레드도 하나밖에 실행하지 못하는 것 아닌가?"

하지만 그렇지 않다.

CPU는 매우 빠른 속도로 여러 작업을 번갈아 실행한다.

```text
스레드 A → 스레드 B → 스레드 A → 스레드 C → 스레드 B → ...
```

이처럼 CPU가 작업을 빠르게 번갈아 실행하기 때문에 사용자는 여러 작업이 **동시에 실행되는 것처럼** 느낄 수 있다.

즉,

> **하드웨어 스레드의 수와 소프트웨어 스레드의 수는 같은 개념이 아니다.**

---

# 9. 하드웨어 스레드 vs 소프트웨어 스레드

| 구분    | 하드웨어 스레드                     | 소프트웨어 스레드                |
| ----- | ---------------------------- | ------------------------ |
| 의미    | CPU가 하드웨어적으로 처리할 수 있는 명령어 흐름 | 프로그램에서 독립적으로 실행되는 작업 단위  |
| 관련 대상 | CPU                          | 프로그램 / 운영체제              |
| 다른 표현 | 논리 프로세서                      | 실행 단위                    |
| 핵심    | 하나의 코어가 여러 명령어 흐름을 처리        | 하나의 프로그램을 여러 작업으로 나누어 실행 |

---

# 10. 내가 이해한 핵심

이번 내용을 공부하면서 가장 중요하다고 생각한 부분은 **CPU의 성능을 높이는 방법이 단순히 클럭 속도를 높이는 것만은 아니라는 것**이다.

처음에는

> **"CPU가 빠르게 동작하려면 클럭을 높이면 되는 것 아닌가?"**

라고 생각할 수 있다.

하지만 클럭을 계속 높이면 발열과 전력 소모 문제가 발생할 수 있기 때문에 다른 방법도 필요하다.

그래서 CPU에는 여러 개의 **코어**를 넣거나, 하나의 코어가 여러 **하드웨어 스레드**를 처리하도록 설계할 수 있다.

또한 프로그램 입장에서는 **소프트웨어 스레드**를 만들어 여러 작업을 나누어 처리할 수 있다.

---

# 11. ⭐ 오늘의 핵심 정리

```text
CPU 성능을 높이는 방법
        │
        ├── 클럭 속도 ↑
        │
        ├── 코어 수 ↑
        │
        └── 하드웨어 스레드 ↑
```

### 클럭

> 1초에 클럭이 반복되는 횟수
> 단위: Hz

### 코어

> CPU 내부에서 명령어를 실행하는 핵심적인 처리 장치

### 멀티코어

> 하나의 CPU에 여러 개의 코어가 존재하는 구조

### 하드웨어 스레드

> 하나의 코어가 처리할 수 있는 여러 명령어 흐름의 단위

### 소프트웨어 스레드

> 하나의 프로그램에서 독립적으로 실행되는 작업 단위

---

## 💡 한 문장으로 정리

> **빠른 CPU를 만들기 위해서는 클럭 속도를 높이는 방법뿐만 아니라, 여러 코어를 사용하거나 하나의 코어가 여러 하드웨어 스레드를 처리하도록 설계하는 방법도 있다.**

그리고 프로그램에서는 소프트웨어 스레드를 활용하여 여러 작업을 나누어 실행할 수 있다.
