# [ 09 - 1 운영체제를 알아야 하는 이유 ]

## 1. 운영체제란?

**운영체제(OS, Operating System)**
: 컴퓨터의 하드웨어와 응용 프로그램 사이에서 **자원을 관리하고 프로그램이 올바르게 실행되도록 돕는 특별한 프로그램**

예시: **Windows, macOS, Linux, iOS, Android**

모든 프로그램은 실행되기 위해 컴퓨터의 **자원(resource)**을 필요로 한다.

> **자원 = 프로그램 실행에 필요한 컴퓨터의 요소**

컴퓨터 구조에서 배운 주요 자원에는 **CPU, 메모리, 보조기억장치, 입출력장치** 등이 있다.

```
응용 프로그램
      ↓
   운영체제
      ↓
컴퓨터 하드웨어
```

즉, 운영체제는 **응용 프로그램과 하드웨어 사이를 연결하는 역할**을 한다.

---

# 2. 운영체제가 필요한 이유

프로그램이 실행되려면 메모리, CPU, 입출력장치 등의 자원을 사용해야 한다.

운영체제는 이러한 자원을 프로그램에 적절하게 **할당하고 관리**한다.

### 메모리 관리

프로그램을 실행할 때 필요한 공간을 메모리에 할당하고, 프로그램이 종료되면 사용하던 공간을 회수한다.

### CPU 관리

여러 프로그램이 동시에 실행될 때 어떤 프로그램을 먼저 실행할지, CPU를 얼마나 사용할지 등을 관리한다.

### 입출력장치 관리

키보드, 마우스, 저장장치 등의 입출력장치를 프로그램이 사용할 수 있도록 관리한다.

### 파일 시스템 관리

보조기억장치에 저장된 정보를 **파일과 폴더(디렉터리)** 단위로 관리한다.

---

# 3. 운영체제는 어디에 저장될까?

운영체제도 하나의 프로그램이므로 실행되기 위해 메모리에 적재되어야 한다.

다만 운영체제는 매우 중요한 프로그램이므로 메모리의 **커널 영역**에 적재된다.

메모리는 크게 다음과 같이 구분해서 생각할 수 있다.

```
메모리
┌──────────────────┐
│   커널 영역       │ ← 운영체제
├──────────────────┤
│   사용자 영역     │ ← 응용 프로그램
│                  │
│   게임            │
│   웹 브라우저     │
│   메모장          │
└──────────────────┘
```

* **커널 영역** : 운영체제의 핵심 기능이 실행되는 영역
* **사용자 영역** : 우리가 사용하는 응용 프로그램이 실행되는 영역

---

# 4. 운영체제는 어떤 일을 하는가?

운영체제는 컴퓨터의 다양한 자원을 관리한다.

| 관리 대상      | 운영체제의 역할              |
| ---------- | --------------------- |
| **CPU**    | 어떤 프로세스에 CPU를 할당할지 관리 |
| **메모리**    | 프로그램에 메모리를 할당하고 회수    |
| **입출력장치**  | 장치 사용 및 입출력 작업 관리     |
| **보조기억장치** | 파일과 디렉터리 등을 관리        |

따라서 운영체제는 단순히 컴퓨터를 켜기 위한 프로그램이 아니라,

> **컴퓨터의 자원을 효율적으로 관리하면서 프로그램이 안전하게 실행되도록 하는 프로그램**

이라고 이해하면 된다.

---

# 5. 운영체제가 개발자에게 중요한 이유

프로그램이 하드웨어를 직접 제어하려면 매우 복잡한 작업을 직접 처리해야 한다.

예를 들어 화면에 문자를 출력하는 간단한 작업도 운영체제의 도움을 받을 수 있다.

```
프로그램
   ↓
운영체제에 요청
   ↓
하드웨어 제어
   ↓
화면에 출력
```

운영체제가 없다면 프로그램이 하드웨어를 직접 제어하기 위한 코드를 훨씬 많이 작성해야 한다.

따라서 개발자는 운영체제를 이해함으로써

> **"내 프로그램이 컴퓨터 내부에서 어떻게 실행되는가?"**

를 이해할 수 있다.

또한 프로그램에 문제가 발생했을 때 운영체제가 제공하는 오류 메시지나 상태 정보를 통해 **문제의 원인을 분석하고 해결하는 데 도움**을 받을 수 있다.

# [ 09 - 2 운영체제의 큰 그림 ]

## 1. 커널

운영체제에서 가장 핵심적인 부분을 **커널(Kernel)**이라고 한다.

> **커널 = 운영체제의 핵심 기능을 담당하는 부분**

커널은 컴퓨터의 자원에 접근하고 관리하며, 프로그램이 안전하게 실행될 수 있도록 한다.

대표적인 기능은 다음과 같다.

**프로세스 관리 / CPU 관리 / 메모리 관리 / 입출력장치 관리 / 파일 시스템 관리**

---

## 2. 커널과 사용자 인터페이스

운영체제에는 커널 외에도 여러 요소가 포함된다.

대표적인 것이 **사용자 인터페이스(UI)**다.

```
운영체제
├── 커널
│   ├── CPU 관리
│   ├── 메모리 관리
│   ├── 프로세스 관리
│   ├── 입출력장치 관리
│   └── 파일 시스템 관리
│
└── 사용자 인터페이스
    ├── GUI
    └── CLI
```

**사용자 인터페이스**는 사용자가 운영체제와 상호작용하기 위한 통로이고, **커널은 운영체제의 핵심 자원 관리 기능**을 담당한다.

---

# 3. 응용 프로그램은 하드웨어에 직접 접근할 수 있을까?

**일반적인 응용 프로그램은 하드웨어의 자원에 직접 접근할 수 없다.**

예를 들어 게임이 하드디스크에 데이터를 저장하려고 한다고 하자.

```
게임
 ↓
운영체제에 요청
 ↓
운영체제
 ↓
저장장치
```

응용 프로그램이 운영체제를 거치도록 하는 이유는 **자원을 보호하기 위해서**다.

만약 모든 프로그램이 하드웨어에 마음대로 접근할 수 있다면 다른 프로그램의 메모리를 변경하거나 중요한 시스템 자원을 함부로 사용할 수도 있다.

따라서 운영체제는 **응용 프로그램이 자원에 접근하는 것을 관리하고 통제**한다.

---

# 4. 이중 모드

운영체제는 CPU가 실행하는 프로그램을 크게 **사용자 모드와 커널 모드**로 구분한다.

이것을 **이중 모드(Dual Mode)**라고 한다.

| 구분       | 사용자 모드       | 커널 모드     |
| -------- | ------------ | --------- |
| 대상       | 일반 응용 프로그램   | 운영체제      |
| 자원 접근    | 제한됨          | 가능        |
| 특권 명령 실행 | 제한됨          | 가능        |
| 목적       | 안전하게 프로그램 실행 | 시스템 자원 관리 |

### 사용자 모드

일반적인 응용 프로그램이 실행되는 모드다.

* 하드웨어 자원에 직접 접근할 수 없음
* 일부 특권 명령 실행 불가
* 운영체제의 서비스를 직접 실행할 수 없음

### 커널 모드

운영체제의 핵심 코드가 실행되는 모드다.

* 시스템 자원에 접근 가능
* 특권 명령 실행 가능
* 하드웨어를 제어할 수 있음

CPU는 **플래그(모드 비트 등)**를 통해 현재 실행 모드를 구분한다.

> ⭐ 핵심은 **응용 프로그램은 제한된 사용자 모드에서 실행되고, 운영체제가 필요한 작업을 대신 처리한다**는 것이다.

---

# 5. 시스템 호출

그렇다면 사용자 모드에서 실행되는 프로그램은 어떻게 운영체제의 도움을 받을까?

이때 사용하는 것이 **시스템 호출(System Call)**이다.

**시스템 호출**
: 응용 프로그램이 운영체제의 서비스를 요청하기 위한 방법

예를 들어 파일을 읽거나, 데이터를 저장하거나, 화면에 출력하는 등의 작업이 필요할 때 운영체제에 요청한다.

```
응용 프로그램
      ↓
 시스템 호출
      ↓
 사용자 모드 → 커널 모드
      ↓
운영체제의 서비스 실행
      ↓
커널 모드 → 사용자 모드
      ↓
응용 프로그램 계속 실행
```

시스템 호출은 CPU의 관점에서는 **소프트웨어 인터럽트와 유사한 방식으로 처리**되어 커널 코드로 진입한다.

> ⭐ **시스템 호출 = 응용 프로그램이 운영체제에게 "이 작업을 해주세요"라고 요청하는 통로**

---

# 6. 운영체제가 관리하는 주요 자원

## CPU 관리

여러 프로그램이 동시에 실행될 때 운영체제는 CPU를 어떤 프로세스에 얼마나 할당할지 결정한다.

이를 **CPU 스케줄링**이라고 한다.

```
프로세스 A ─┐
프로세스 B ─┼→ 운영체제 → CPU 할당
프로세스 C ─┘
```

---

## 메모리 관리

프로그램이 실행되려면 메모리가 필요하다.

운영체제는 프로그램이 사용할 메모리 공간을 관리하고, 필요에 따라 메모리를 효율적으로 사용할 수 있도록 한다.

대표적인 메모리 관리 기법으로 **페이징, 스와핑** 등이 있다.

> 이 부분은 뒤에서 메모리 관리 단원에서 자세히 배우게 된다.

---

## 프로세스 관리

**프로세스 = 실행 중인 프로그램**

운영체제에서는 여러 프로세스가 생성되고 실행되며 종료된다.

따라서 운영체제는 프로세스의 실행 상태와 자원 등을 관리해야 한다.

이후에는 **프로세스와 스레드, 프로세스 동기화, 교착 상태** 등을 배우게 된다.

---

## 입출력장치 관리

키보드, 마우스, 저장장치 등의 입출력장치를 관리한다.

앞에서 배운 **장치 드라이버, 장치 컨트롤러, 인터럽트** 등이 운영체제의 입출력 관리와 연결된다.

---

## 파일 시스템 관리

보조기억장치에 저장되는 정보를 **파일**이라는 단위로 관리하고, 파일을 다시 **폴더(디렉터리)**로 묶어 관리한다.

```
저장장치
  ↓
파일
  ↓
폴더(디렉터리)
```

**운영체제**

**커널**

> CPU의 실행 모드를 사용자 모드와 커널 모드로 구분하여 자원을 보호하는 방식

> 여러 프로세스에 CPU를 어떻게 할당할지 관리하는 것

> 실행 중인 프로그램
